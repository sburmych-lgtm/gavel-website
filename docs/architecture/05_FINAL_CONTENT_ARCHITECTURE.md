# 05 · FINAL CONTENT ARCHITECTURE

All copy lives in `src/content/`. No user-facing string appears in markup. This
is what makes a content lock possible later without touching components, and
what lets the facts guard scan one place.

Language is Ukrainian throughout. `lang="uk"`. No English headlines.

The English stroke names are set small in mono beside the Ukrainian. They are
what make the metaphor legible as a real technical sequence rather than
decoration, and they answer the objection that a metaphor obscures the method.

## Content model

```ts
site      { name, romanised, role, city, venue, instagram, year }
hero      { eyebrow, title[], lead, ctaPrimary, ctaSecondary }
proof     { value, label }[]
fit       { eyebrow, h2, lead, items[{ n, title, body }] }
method    { eyebrow, h2, lead, close, phases[{ n, ua, en, body }] }
results   { eyebrow, h2, lead, featured{before,after,alt}, supporting[], disclaimer }
formats   { eyebrow, h2, rows[{ title, where, body }], included[] }
pricing   { eyebrow, h2, lead, tiers[{ name, price, currency, includes, featured }], note, limit }
coach     { eyebrow, h2, paragraphs[], caption }
athlete   { eyebrow, h2, paragraphs[] }
creds     { eyebrow, h2, groups[{ title, items[] }] }
faq       { eyebrow, h2, items[{ q, a }] }
contact   { eyebrow, h2, lead, cta, formNote, fields[] }
```

Prices carry an explicit `currency` field rather than a formatted string,
because that is what stops a later edit from silently "unifying" ₴ and $.
