# IGOR GAVRILEYKO — coded visual prototype

Personal-trainer site for **Igor Gavrileyko** (Ігор Гаврилейко) — Lviv, fitness
centre «Пляж» (Aquapark). Master of Sport of Ukraine in canoe and Dragonboat
paddling; 26 years in sport, 16 coaching.

This repository is the **frontend visual prototype**, built from the frozen
architecture in `docs/architecture/`. It is production-shaped — it is intended
to become the production frontend after human visual approval — but it is not
production: there is no backend, and the contact form uses an isolated mock
adapter.

## Run locally

```bash
npm install
npm run dev
```

Dev server: <http://localhost:4321>

```bash
npm run build
npm run preview
```

## Layout

```
scripts/          media pipeline + font vendoring (run manually, not in build)
src/content/      every string and asset reference — no copy lives in markup
src/styles/       design tokens, base layer, generated font faces
src/components/   reusable primitives (MediaFrame, BeforeAfter, Reveal…)
src/sections/     one file per page section
src/pages/        routes
public/media/     derived web media (generated by scripts/build-media.sh)
docs/             architecture, decisions, worklog, handoff, QA evidence
```

## Source assets

The read-only asset library lives outside this repository at
`G:\01_PROJECTS\Web Design\ihor_havryleiko_fitnesstrainer\Assets`.
Nothing here writes to it. `scripts/build-media.sh` reads from it and emits
derivatives into `public/media/`.

## Non-negotiables

Fixed client decisions, not preferences. See `docs/DECISIONS.md`.

- Brand spelling is exactly **IGOR GAVRILEYKO**.
- H1 is exactly **«Сила викована водою»**.
- Water/canoe owns the first impression. No gym-first hero, no splash screen.
- A draggable Before/After slider is mandatory.
- «Майстер спорту України» must never become «міжнародного класу».
